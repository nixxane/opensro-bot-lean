# Bug reports go to GitHub
- The bug-report button now files reports as public GitHub issues, where an automatic workflow tries to fix them, instead of posting to Discord.
- The button now says "Send to GitHub" and the preview warns that a report becomes a public issue, so check your explanation and screenshot for private details first. Diagnostics still omit names, chat and locations.
- Sending works the same way; only where the report lands has changed.
> Tested with the integration suite and mocked GitHub/Cloudflare requests; the live service has not been exercised.
