# Max every skill is now a switch
- "Max every skill" (Settings, Auto mastery) is now an on/off switch instead of a one-time button. While it is on, it learns and upgrades every skill it is allowed to, then stays on and spends new skill points as you get them (after a level up, for example). Turn it off to stop.
- It is off by default and saved per character. Passes that find nothing new stay quiet (no toast every few seconds), and a level the game refused is not resent for a minute.

> Tested in simulation only, not in a live game.
