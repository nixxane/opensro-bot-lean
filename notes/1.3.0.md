# Team relay (phase 1: presence)
- New Team page: connect several characters through your own WebSocket relay; while it runs, each character sees the others' presence (name, hunting, alive, level) in the panel.
- A reference relay server (rooms by room key, presence forwarding, no game logic) is included under relay/ in the repository.
- Presence is private to one room key; nothing is shared beyond it. The bot never depends on the relay: off or unreachable, everything else works exactly as before.
> Presence, heartbeats and reconnection are tested in simulation only; a live relay check is still to do.
