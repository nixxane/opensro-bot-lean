# Bot reloads the page when a reconnect hangs
- If the "Reconnecting…" message in the bot panel has not changed for 3 minutes, the bot now reloads the game page by itself, instead of waiting forever for a server that never answers.
- Your character and hunting state are kept, and hunting resumes after the world loads again.
- A slow reconnect that is still moving through login and world entry starts the wait over, so it is not cut short.
- Reloads in a row wait longer each time, and the 12-hour limit still stops the bot and asks you to reload by hand.
> Contributed by NiftyOps (#108). Tested in simulation only, not in a live game.
