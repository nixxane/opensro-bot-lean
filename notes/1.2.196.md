# Shorter page list in the wide window
- In the wide window, the page list now shows one row per page: a small icon with the name beside it, like the Classic window's sidebar.
- The wide window is about 190 px shorter, and the page list column is a little wider to fit the names.
> Tested in simulation only, not in a live game. The layout was checked on a screenshot replica, not in a real browser.
