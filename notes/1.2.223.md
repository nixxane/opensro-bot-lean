# Town trips no longer hang before the return scroll
- If the game keeps showing a pending inventory or an open cast when the bot is about to read the return scroll, the town trip used to wait forever. It now shows "Waiting for the game to settle before the return scroll."
- After a full minute of that, the trip stops cleanly and hunting stays off. The bot never sends the scroll twice. Reload the game and check your character.
- If the game refuses the return scroll three times without giving a reason, the message now says the game itself may be refusing it and suggests using the scroll by hand.
- No new option.

> Contributed by duan78 (#95). Tested in simulation only, not in a live game.
