# Keep self buffs up while walking back

- Each buff in Combat > Buffs & imbue now has a Keep (skill) up choice: While hunting, or Hunting and walk-back. The default is While hunting, so nothing changes unless you pick the other one.
- Buffs set to Hunting and walk-back are also cast while the bot walks back to the hunting spot or between towns, so speed or stealth skills stay on for the whole trip.
- Buffs saved before this choice existed keep working only while hunting.

> Contributed by duan78 (#84). Tested in simulation only, not in a live game.
