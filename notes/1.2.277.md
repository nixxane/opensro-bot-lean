# Start and stop characters from the live dashboard
- New setting on the Settings page, under Live dashboard: "Allow Start and Stop from the dashboard". Off by default, set per character.
- When it is on, that character's dashboard card gets a Start or Stop button, and Start all / Stop all sit at the top and ask before acting.
- Stop does the same as Stop all in the bot panel, so it also cancels auto-start. Start only acts while the bot is stopped, so a late Start never stops a running bot.
- The command reaches the game with the character's next report (about every 10 seconds). A command older than 90 seconds is ignored, so a bot that comes back later does not act on an old one.
- Anyone with your dashboard link can start and stop the characters that allow it, so keep the link private.
> Contributed by alexg-93 (#111). Tested with the integration, hub and dashboard test suites and in a live game from a phone using the self-hosted hub; not tested on a deployed Cloudflare Worker.
