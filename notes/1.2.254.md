# Leveling never uses wall skills, and you can pick a character build
- Zero-setup leveling no longer uses Crystal Wall and Fire Wall (they keep the character from moving). Teleports, dashes, hides, traps, auras and transforms are left out too.
- Wall skills that leveling added to an existing profile are taken out. Skills you added yourself stay.
- New "Character build" choice in zero-setup leveling: Auto (as before, minus the blocked skills), or Glaive nuker, Spear fighter, Blade tank, Sword fighter, Bow nuker, Force support, Wizard, Warlock, Warrior, Rogue, Cleric, Bard.
- A build sets the masteries and their order, learns only its own skills, puts them in its order, uses one imbue and buys its weapon type (and a shield) on a town trip. Enhanced or protected gear is never replaced.
- Changing the build starts the setup again for that character. Skills already learned stay learned; skill points are not refunded.
> Only tested in simulation. Not tried on the live server yet. The builds come from community guides and the game data, so check one before you rely on it.
