# One switch for Reverse Return Scrolls
- Reverse Return Scrolls now have a single switch, on the Town page under "Back to the hunting spot": "Buy Reverse Return Scrolls from the Item mall (silk)". The old merchant switch is gone (no merchant sells them for gold, and it could start useless town trips); if it was on, the new switch is turned on for you.
- On a town trip without a reverse scroll, the bot now buys one from the Item mall after the services and reverses. Before, the mall only bought while hunting, so the trip often walked back instead. If the mall cannot deliver (budget, silk, full bag, refused), the trip walks back as before.
- The reverse switch works without the general "Buy from the Item mall" switch; it still uses the silk budget per bot run. "Low stock ≤" now really means "or equal". When the same item is listed more than once in the mall, the single-item package is bought.

> Tested in simulation only, not in a live game.
