# Update button and window layout fixes
- The **Update** button can be clicked again in the compact window. When an update was available, the button wrapped to a second header row and the "Update available" line covered it.
- The classic window keeps one size on every tab again, instead of shrinking on short tabs such as Player buffing. It is still capped to your screen height.
- The wide window splits a page's boxes into its two columns as evenly as possible, so a tall box no longer leaves a long empty gap beside it.

> Checked in the bot's browser UI test (Edge, simulated game), not in a live game.
