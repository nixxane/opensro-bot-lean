# Spare giants and party monsters near death
- New hunt option "Spare engaged giant/party below % HP (0 = off)", next to "Avoid other players' targets". The default is 50, and the highest value is 50.
- It applies when "Avoided monsters" is set to "Normal & champion only". A giant or party monster that another player is already fighting is now skipped once its health is at or below that percentage, because the drop is probably theirs by then. The bot goes for a fresh target instead.
- Above the cutoff, or when the monster's health is unknown, these monsters are still attacked as before. Elite, unique and titan monsters are not affected.
- Because the default is 50, existing characters on "Normal & champion only" will start sparing these monsters. Set it to 0 to turn this off.

> Contributed by duan78 (#93). Tested in simulation only, not in a live game.
