# Town trips wait when the warehouse will not open
- If the warehouse, a merchant or the world statue does not open, for example because the town is still loading, the bot no longer stops. It waits a minute, walks back and tries again.
- Each service gets three tries per trip. If the third one fails too, the bot stops with the same message as before.
- No new option.

> From a player report. Tested in simulation only, not in a live game; a slow-loading town is the likely cause, not a confirmed one.
