# Coherence fixes for the team layer
- A unique's death reported by a teammate is recorded quietly; it used to be re-announced, which echoed between clients forever.
- A teammate's store write no longer cancels the sync this client still owes the room (a pending local sighting could be lost until the next change).
- Moving the hunting spot from the tracker cancels any automatic unique converge, so its later restore cannot overwrite the manual spot.
- Shared live intel is cleared when the character changes; the "Hunt here" button still works the same.
> Found by re-reading the code with two clients in mind; tested in simulation, not yet with real characters.
