# More enhancement attempts per run
- The **Maximum attempts** option (Alchemy page, Item enhancement) now goes up to 9999. It used to stop at 1000.
- A run still stops when it reaches the target + or when the elixirs, powder or stones run out.
- The limits for stone fusion and attribute stones are unchanged.
- The manual and the start message are updated to say 9999.
> Contributed by corevider (#72). Tested in simulation only, not in a live game.
