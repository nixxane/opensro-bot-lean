# Optional auto-login after a server restart
- New setting under Behaviour: "Log in again by itself after a server restart". Off by default.
- While it is on, the bot remembers the ID, password and server of your next login on the game's login screen. When a disconnect ends with you signed out, it logs in again, enters the same character and carries on hunting.
- Turned on while already in game? Log out and log in once so it can remember the login.
- The login is kept unencrypted in this browser's storage for the site; anyone using the same browser profile can read it. Turning the setting off forgets it. It never goes into logs, diagnostics, reports or shared profiles.
- If the server refuses the login three times (wrong password, for example) it stops and waits for you; a server that is still restarting is tried again every few minutes.
> Tested with the integration suite against simulated game states; a real server restart has not been exercised yet.
