# Leveling makes Donwhang the return point before hunting there
- A Jangan character could teleport to Donwhang and hunt there with the return point still in Jangan. When Jangan had no hunting spot near the character's level, the bot picked a Donwhang spot and simply travelled to it, skipping the move. Every death and return scroll then went back to Jangan.
- Now a hunting spot near another town always starts the move first: the bot goes to that town's world statue, makes it the return point, and only hunts there once the game confirms it. With "Move to the next town" off, it never hunts around another town.
- A move that fails no longer gives up on that town for the whole session. The log says the return point is unchanged, and the bot tries again after 10 minutes.

> Tested in simulation only, not in a live game.
