# Auto quest: pick quests from a list

- The Quest page now has a list of quests to tick, like phBot. Each shows its level and name. The list comes from the game's own quest data (about 140 quests whose NPC the data names).
- Ticked quests are done lowest level first: the bot walks to the quest NPC from the game's NPC table (it can cross regions, outdoors), takes the quest, hunts what the quest counts and turns it in. Quests above your level wait.
- Quest codenames now come from the data, so the right dialogue row is picked without learning it first. The journal's own target list is hunted first.
- With nothing ticked it still follows the quest markers the game shows. The status line says what it is waiting for.

> Only tested in simulation and against the game data files. Monster spawns are not in the client, so the bot hunts where your hunting area already is. Not checked on the live server.
