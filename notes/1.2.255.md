# Leveling keeps the weapon type your character started with
- A blade character could end up buying swords. Auto-equip treated every weapon as the same kind, so a dropped sword with better stats replaced the blade, and leveling then bought the next sword at every tier.
- With Level up by itself on, the bot now remembers the weapon type your character had when leveling first saw it (a new character's starting weapon) and keeps buying that type. If it holds another type, the next town trip buys the right one back. Choosing a build in "Character build" still decides the weapon instead.
- Auto-equip now only swaps a weapon for one of the same type.
- A character that already switched type is remembered with the weapon it holds now. If that is wrong, pick a build with the right weapon in "Character build".

> Tested in simulation only, not in a live game.
