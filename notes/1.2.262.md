# Discord session reports
- Post the current hunting-session totals to your own Discord webhook every 1 to 60 minutes.
- Off by default, and it needs your own Discord webhook address saved; a shared settings code never carries the address.
- The report keeps coming while the bot is stopped, dead or out of the game, and says which state it is in.
- Send a test report from Settings, and see when the next one is due or why the last one failed.
- A webhook Discord refuses switches reports off instead of retrying forever.
- The webhook address is kept in this browser only; it is not part of shared settings or backups and is never logged.
> Only tested in simulation: no live Discord message was sent by the tests.
