# Bot reloads when a walk never gets collision data
- If a town trip or walk back has been waiting on "Waiting for game collision data" for 3 minutes, the bot now reloads the game page by itself instead of waiting forever.
- Your character and hunting are kept, and hunting resumes once the world loads again.
- This only happens while the bot is working (hunting, a town trip or a walk back); a stopped bot never reloads.
- Reloads in a row wait longer each time (3, 6, 12 minutes and so on, up to 30), and the count clears once collision data arrives.
- If the game sends collision data the bot cannot use, it does not reload and shows the reason instead.
> Contributed by NiftyOps (#109). Tested in simulation only, not in a live game; the lost collision data case was not reproduced on a live server.
